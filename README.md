
# 🐍 Python Utility Toolkit

A modular command-line application developed in Python as part of my Computer Science learning journey.

The project brings together five utilities in a single interactive menu, demonstrating fundamental programming concepts and modular software design.

## ✨ Features

- **Prime Number Checker** — Check whether an integer is prime.
- **Power Calculator** — Calculate the square and cube of a number.
- **Circle Area Calculator** — Calculate a circle's area from its radius.
- **Random Number Generator** — Generate a random integer between 1 and 100.
- **Polygon Perimeter Calculator** — Calculate the perimeter of a polygon using Cartesian coordinates.

## 🛠️ Technologies

- Python 3
- Python Standard Library
- Modular Programming
- Exception Handling
- Command-Line Interface (CLI)

## 🚀 Getting Started

### Requirements

Python 3 installed on your computer.

### Run the Application

Clone the repository:

```bash
git clone https://github.com/domenicomaggio/python-utility-toolkit.git
```

Open the project directory:

```bash
cd python-utility-toolkit
```

Run the application:

```bash
python3 main.py
```
